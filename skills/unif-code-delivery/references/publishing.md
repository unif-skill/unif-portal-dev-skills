# Unif RN 库发布

发布前核对[包身份](package-naming.md)、[GitHub 采用](github.md)及目标工程当前发布 workflow。组织身份与非敏感参数来自工程 `.github/organization.json`，采用该流程后不从技能缓存读取运行配置。

组织发布 App ID 为组织资产中的 releaseAppId，当前为 3890760；它是发布机器人身份，不是私钥。workflow 的 App ID 变量及私钥 secret 继续由平台提供，原有变量名称与绑定以实际 workflow 为准。确认机器人获准执行当前受保护分支操作，不以个人账号可以 publish 代替组织链路。

首次发布先确认注册表是否已有同名包、npm 组织权限、目标仓库、公开包产物和当前可信发布绑定；存在历史时按恢复发布核对已发布版本与 tag。找不到历史或绑定不完整时明确缺口，不从开发机试发、不重用历史版本、不临时放宽保护。

常规交付沿用工程 PR、required 检查、机器人／OIDC 以及已采用的版本写回流程。版本变更只在已授权主版本内按 minor／patch 处理；主版本升级需单独明确授权。发布依据覆盖当前提交、包内容、公开消费和必要平台验证，文档构建与 Pages 部署分别确认。

Git 提交、PR、Release 与注册表实际发布分别报告；准备完成不等于已发布。
