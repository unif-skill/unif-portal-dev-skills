# 审查规范

审查者必须取得本次适用的企业依据，将其用于当前审查：

- 客户端文件、依赖、组件与测试：加载本插件 code-development，按变更类别读取主题。
- 模块职责、公共契约、状态与调用交接：加载本插件 architecture-design，选读相关规则和目标模块契约。
- 审查范围包含本次变更的实际实现及消费者；规范版本和契约来源随审查材料提供。

企业规范问题应指出违反的规则、代码位置与实际影响。已有契约覆盖的等价整理不要求重新设计；评测样例与通用风格偏好不能成为新增需求。本技能不安排第二轮审查，也不替代当前流程的问题处理与操作授权。
