# 后端代码开发

按已确认职责和实际消费者完成后端实现。优先采用目标工程指定的规范修订；同一上下文中已读且仍适用的内容直接复用，按本次范围选择资料：

- 修改范围、现有行为和依赖选用：[实施范围](references/scope.md)。
- 文件拆分、提示词归属、包公共入口与调用方向：[目录与依赖](references/structure.md)。
- 异步执行、取消、收尾、事务及调用预算：[运行与资源](references/lifecycle.md)。
- 同源契约、任务指令、消费者接线和验证证据：[契约与验证](references/validation.md)。

先确定修改单元及其输入、输出、副作用和状态所有者。结构重构对照实际装配文本、事务、资源路径与消费者；发现行为缺陷时保留可复现条件并执行相应回归。通过所属工程现有检查验证实际改动。

模块职责、公共契约或状态归属实质变化时使用 architecture-design；测试、审查和交付沿用相应阶段入口。取得相关规范不启动重复流程，不扩展用户授权。领域契约从工程采用的架构源取得，来源记录见 references/source.json；未安装本技能时可直接采用工程指定的同一规范源。
