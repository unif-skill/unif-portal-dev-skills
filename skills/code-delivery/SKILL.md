# 交付规范

在当前交付流程中必须核对工程采用的企业规则和验收证据：

- 本工程的 AGENTS.md、贡献约定、检查脚本和 CI：分支、提交、门禁及版本发布规则。
- 涉及客户端代码的验证范围与证据层级：加载本插件 code-development，读取“测试与验收”主题。
- 涉及跨仓公共契约时：加载本插件 architecture-design，读取“独立验证”及相关契约，核对消费者和部署兼容范围。

证据对应当前提交、配置和实际执行层级，定向验证不替代工程门禁。按任务授权交付；本技能不定义 Git 分支模型、操作菜单、清理算法或额外发布规则。
