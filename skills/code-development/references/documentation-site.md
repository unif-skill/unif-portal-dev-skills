# React Native 库文档站与组件 Web 示例

本专题用于 RN 库。原生鸿蒙库文档与 ArkUI 运行示例采用[鸿蒙公开入口与文档规则](harmony-files.md)及[鸿蒙测试与验收](harmony-testing.md)，不套用下述 RN Web、Snack 或 iOS／Android 宿主要求。

## 依据与入口

从所属库工程入口、开发文档、根与 website 的包配置及代表页面确认标准，区分正式文档、调试页和原生 example。缺少依据时定向参考 Design、Camera、HMS Scan；在建站点仅供了解实现。

正式文档站采用 Docusaurus，面向使用者的组件 Web 示例进入其组件页；Vite 可保留开发调试用途。按本次页面接入，不顺带改造整站。

参考路径相对于对应库根目录，按问题选读：

| 内容 | 位置 |
|---|---|
| 品牌、导航、目录 | 本站 `website/docusaurus.config.*`、`sidebars.*`、首页与 CSS，沿用本库名称、能力分组、快速开始、API 和生态链接。 |
| 组件说明与真实预览 | 本站同类页；Design 的 `website/docs/components/*.mdx`、`website/src/components/LiveDemo.tsx`。 |
| 共享样式 | 采用版本公开的 `@unif/react-native-design/docs-home.css` 与 exports，确认适用范围后直接消费。 |
| 宿主与工程接线 | 本站 RN Web 插件、client modules、LiveDemo、生成脚本和 CI；依赖与执行命令取当前配置。 |

## 页面组织

沿用本站样式，按“简短用途与适用范围 → 原生预览或运行入口 → 最小用法 → 必要状态与 API”组织。

- 先确认本次需要的预览平台；已有可用示例沿用现有方式，普通维护不自动迁移到 Snack 或重写演示。用户要求原生预览时，以 iOS／Android 的真实效果为准；采用 Snack 前核对实际 SDK、库的版本要求及原生模块清单，只开放所需平台。需要自定义原生 SDK 或版本不兼容时，说明已有原生 example／开发构建入口，不能伪装成可运行的 Snack。
- Web 预览不是原生文档的必选项。用户只要原生展示时，不为展示增加 Web 兼容、依赖补丁、模块替换或重写组件；只有明确需要且有真实 Web 实现时才提供浏览器交互。
- 预览宽高贴合使用场景，留白清楚，窄屏能收缩或换行；需要滚动时限定预览区域，图片保持比例和合理尺寸。
- 预览、少量状态控件、事件结果分区。主交互由组件完成，控件只切换必要状态；结果区显示当前结果或最近事件，详细诊断按需展开并限制增长。
- 状态按契约选择空、加载、禁用、错误、长内容等，示例接回受控值和原事件。固定演示数据可以使用，组件与交互链路使用真实实现，不附加业务流程。
- 默认文案说明用途、操作和结果，工程术语放入必要的接入说明。用法代码对应当前演示，API 与 types 同源。

## 公共消费与宿主

公共类型、文档生成及发布证据沿用[库开发](library-development.md)。示例从公开入口导入组件与 types；站点可按已有配置将包名解析到源码公共出口，不另写同义 API。

使用 Design 主题、字体或 UI 宿主时按需取得 unif-design 的对应资料，按采用版本的公开接口接入站点明暗模式和大字号，保持字体缩放归属。

原生预览核对所需手势／安全区／弹层宿主及真实依赖。Snack 能加载 npm 的 JS 不代表 Expo Go 已内置其原生模块；不为预览降级库契约、替换原生 SDK 或用 Mock 冒充能力。只有任务包含 Web 预览时，才核对 React 运行时解析、RN Web 入口、Docusaurus 静态渲染和 hydration；参考站的 shim、alias 与依赖不能直接复制。

## 同步与验证

公开出口、types、运行示例、用法与 API 文档随同一源码更新；已有生成链或 llms 资料时改源并同步。核对 CI 是否覆盖网站引用的源码、类型、依赖和生成输入，沿用项目现有检查、构建与发布流程。

开发时先预览真实文档页，再调整布局和交互。网站本体检查桌面／窄屏、明暗主题、中文、导航和刷新；原生预览实际运行所选 iOS／Android 场景并检查组件、状态、弹层与事件结果。iframe 加载成功不能代替原生运行，模拟器也不能代替相机、扫码、分享等真机能力验收。任务包含 Web 交互时再检查其大字号、裁切、滚动、焦点、控制台与 hydration。

分别报告静态检查、站点构建、浏览器操作和相关原生／设备结果。截图与 Mock 不替代真实交互，Web 通过不代表全部平台完成；验证范围限于本次实际影响。
