# 测试规范

执行测试工作前必须取得企业验收依据，将其应用到当前 TDD、调试或验证过程：

- 共同测试责任与质量：加载本插件 architecture-design，读取“独立验证”中的“测试责任”；涉及调用、状态、协议或模型语义时再读相应契约。
- 客户端测试组织、影响范围与平台验证：同时加载本插件 code-development，读取“测试与验收”主题；其他工程采用自身的组织与工具约定。
- 测试预期来自所属模块契约；命令、覆盖范围与超时配置来自实际工程。

核对企业要求是否被测试和消费者接线实际覆盖。测试组织方法沿用当前流程，本技能不另定义 TDD 循环或统一用例模板；缺少必需规范时明确缺口，不把通用测试通过当作企业验收完成。
