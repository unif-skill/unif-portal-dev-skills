# 代码测试

补齐工程的测试质量与行为证据；已有 TDD 或调试流程时在其中完成，不重启一套流程。

## 依据与范围

读取采用的契约、实现、实际消费者与现有测试配置，按行为缺口选择用例。测试组织和命令取自工程，旧测试不决定新需求。

## 用例与执行

- 执行真实被测实现，只替换外部边界。预期来自契约，核对返回、状态、必要调用及不应发生的副作用；不复制实现计算预期，也不用被测函数的替身证明正确。
- 按相关行为验证失败、取消、重复或并发。隔离用例数据与资源，控制异步顺序并等待清理；采用工程的测试超时约束。
- 覆盖率先核对源码统计范围与断言效力，不通过排除有效源码或削弱断言提升数字。回归用例应能揭示原问题，必要时以隔离的错误实现验证其有效性。
- 不稳定测试保留首次失败，核对顺序、共享状态、未结束任务与环境差异，区分产品缺陷和测试问题；重试通过不代表修复。

## 结果

报告实际命令、结果、行为覆盖与剩余缺口。修复后验证受影响部分；替代依赖的结果与真实集成、设备、模型评测及完整 CI 分开。实现缺陷按授权修复或报告，不改契约迎合测试。
