## 3. ArkUI 状态与生命周期

Unif 的账号、角色、会话、草稿及操作权威来源按[平台状态归属](../common/state.md#4-状态归属)确定。登录切换、会话切换和恢复按所属业务契约处理，同名账号重新出现不重新授权旧操作。

| 单元 | 项目中的状态与资源责任 |
|---|---|
| Chat | 展示调用方的消息、输入与附件；应用拥有会话、草稿、上传和停止业务操作的决定 |
| Camera | 本轮捕获、预览选用与文件交付按 Camera 契约；应用承接已选媒体、上传及业务照片关联 |
| Scan | 实时识别与图片借用按 Scan 契约；图片解码不取得调用方文件的删除权 |
| Umeng | 同意后初始化与分享调用按 Umeng 契约；应用准备分享输入，统计和渠道回执保持真实语义 |
| Design | 组件显示、主题派生和局部 UI 请求；应用拥有持久化外观设置及确认后的业务决定 |

各库的取消、接替、成功交付、迟到回调与释放失败按六库原生契约验收；页面离开不撤销已交付媒体，也不自动删除应用草稿或上传资源。
