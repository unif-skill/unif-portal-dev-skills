# 语音能力接入与维护

## 接入应用

从消费者定位既有权限、凭证、词表与草稿流程，再选择 capture、credentials、realtime 或 input 的公开能力。不要在 Hook、页面和业务单元分别维护同一录音轮次；低层会话与界面状态的真实职责差异保留。

按采用版本核对权限重读、实际 PCM、准备期队列、finish 与服务端终态。partial 用于当前展示，final 按实际协议标识采用；相同文字不能自行当重复。失败保留已定稿文字，未确认结果不能标为确认完成，取消不改业务草稿。

身份结束同时关闭所属会话并 dispose 凭证；新输入接管等待旧采集实际释放。权限请求取消、启动失败、停止失败与超时分别检查，不能用页面卸载掩盖麦克风仍占用。

## 原生与维护

从 docs/DEVELOPMENT.md、package.json 子路径出口、实际采集／会话／Hook 和 example 查阅。音频 SDK 的精确版本和补丁由宿主维护；核对实际解析副本与原生编译来源，尤其 Android 是否按当前要求 buildFromSource。OTA 或 Expo Go 不交付该原生修订。

共享日志使用应用已安装运行时。平台凭证服务、长期密钥与业务词表查询不搬入库；采集扩展事件在边界校验，不因官方 SDK 类型不同省略保护。

## 定向验证

- 凭证覆盖取消、忽略信号、迟到缓存、身份释放和错误凭证失效范围。
- 以真实采集→会话→输入消费者验证准备期数据、实际格式、final 去重、终态互斥、停止／关闭及旧轮次迟到事件。
- useVoiceInput 的 transcript 是本轮展示；核对草稿对 text 的 confirmed／unconfirmed、failed 的 finalText 及 cancelled 的采用。text／failed 结果等待本轮必需的采集收尾。user／replaced 的 cancelled 通知可以先于释放，context_ended 静默结束；取消通知不证明设备已释放，新采集仍等待旧轮次的真实释放结果。
- 包消费使用实际 tarball 与完整公开类型夹具；设备另验权限、音频中断、PCM 与麦克风释放。没有厂商服务证据时不宣称真实识别成功。
