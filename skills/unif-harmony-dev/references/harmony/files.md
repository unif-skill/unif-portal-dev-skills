## 2. ArkTS 文件与公共入口

应用源码按[项目目录](directory.md#1-工程目录与依赖)归属，六库按自身能力组织，不承担 Portal 业务目录。Portal 通过六库公开能力组合功能；库不依赖 Portal 私有状态、路由和服务凭据。

六库规范描述目标契约，所属库源码、公开文档和 ArkUI 示例描述已实现出口。具体 API、必要配置及示例由所属库维护，规范不另抄接口全集；尚未实现的目标不以 RN 同名 API 充当原生用法。

Unif 网站与原生示例分别采用各自工程方案；RN 网站的技术选择不传递给原生库。共同逻辑与资源的来源、平台映射和采用修订按[契约与资源归属](integration.md#3-契约与资源归属)登记。
