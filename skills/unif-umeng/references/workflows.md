# 初始化、分享与统计

## 初始化

核对实际采用版本的配置字段、初始化不可变语义与原生回调接线。应用拥有同意记录和调用时机；仅使用统计时按公开契约提供必要配置。初始化中的并发、配置锁定、失败恢复和厂商副作用以本库公共契约为准，不通过重复初始化或自造 preInit 入口绕过。

## 分享

1. 复用已有截图、图片准备或上传能力形成 ShareContent；内容和业务身份属于本次调用快照。
2. 无需选目标时调用 share；需要选择交互时复用 useShareSheet 的 controller 和 host。模态预览窗口挂载自己的实例，不借用另一个窗口的普通页面宿主。
3. SDK 开始前的面板取消与开始后的 signal/卸载分开处理。开始后取消呈现不会撤回第三方 SDK 操作，原调用仍需接收真实结果。
4. 应用依据原场景决定结果是否仍适用；文件在真实使用结束前保持有效。success 不等于接收方阅读、订单提交或文件保存。

## 维护与验证

从 docs/DEVELOPMENT.md、src/index.ts、package.json、common/share/analytics 及相关原生实现定位变更；目标契约为任务采用规范根的 libraries/react-native-umeng.md。共同规则按实际阶段读取。

核对真实消费者、初始化前/失败状态、在途 busy、同实例呈现、原调用回执及统计参数。保留初始化失败、取消和不可判断副作用的错误，不将它们补成成功。

本库 Mock 只替代外部边界。原生链接、URL/Universal Link/Activity 回调、实际第三方应用、取消及统计平台回执分别验证；Web unsupported、单测和打包通过均不替代设备或真实平台结果。
