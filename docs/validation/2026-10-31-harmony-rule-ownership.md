# 鸿蒙规则维护归属

## 当前边界

| 内容 | 维护位置 |
|---|---|
| API 26／V2 开发基线、Context 与平台生命周期、SDK 材质支持范围 | Uni Skills 的 harmonyos-development |
| HAR 公开入口、依赖与资源、打包及独立原生宿主验证流程 | Uni Skills 的 harmonyos-library |
| Unif 产品目标、应用目录、六库分工、厂商、业务身份与协议 | Unif 架构规范及生成专题 |
| 各库具体输入输出、取消与资源交接、视觉及消费者验收 | 所属六库契约 |

Unif 不再维护 V2 的独立选择或兼容例外，也不复制平台 SDK 支持表。API 26 在 Unif 规范中仅表示当前产品目标。六库对相机选用、图片借用、草稿、分享回执及 UI 交互的要求属于公共行为契约，继续保留。

同一 Unif 源章节可以随独立技能生成多份专题，均由来源摘要和同步检查约束；这不构成多个手工维护源。两插件之间没有强制安装、调用或文件引用。

## 核对范围

核对两份鸿蒙项目规范、六库原生契约，以及开发、测试、审查和交付四组生成专题。通用材质规则移入 Uni；项目规范与专题不重新定义平台规则。历史计划和验收记录保留其原有版本语境，不作为另一份现行规范修改。

## 验证结果

101 项维护脚本回归、17 个 Unif 技能目录、7 个 Uni 技能目录及 11 组同源检查通过。独立审查核对规则归属、六库契约、两个通用技能的单目录使用及 Unif 独立分发，未发现待处理问题。本次仅验证规范与技能，未执行原生产品构建、设备或业务验收。
