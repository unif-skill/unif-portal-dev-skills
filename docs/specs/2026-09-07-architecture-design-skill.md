# 架构与模块设计技能

## 职责

`architecture-design` 服务 Unif Portal 产品的研发设计与审查，覆盖客户端及相关 Agent、Channel、CLI 工程；产品运行时的业务任务另行维护。

技能帮助新会话根据本次需求和目标契约完成模块边界、调用交接、状态归属与验证范围的设计。入口保留必要判断和阅读指引，详细架构原则由规范源维护。

## 资料与分发

- 技能分发内容为 `SKILL.md`、平台规范快照及来源记录，完整目录可独立搬移。
- 规范优先采用任务或目标工程指定的版本；未指定时使用包内快照。领域契约按需读取。
- 公共名称和语义来自目标模块契约，未确认接口标为草案；评测样本不作为真实 API 的依据。
- 根 `plugin.json` 与 `skills/` 组成标准插件。同步范围、分发方式及格式标准见 [README](../../README.md)。

## 验收

1. 技能及插件格式合法，包内引用可解析，完整目录搬移后可读取。
2. 快照保留规范正文并记录来源摘要；同步检查能识别源、快照或来源记录的变化，检查本身不改文件。
3. 设计能从入口输入走到结果，交接、错误、副作用、状态与确认有明确契约依据；新增公共边界有实际消费者。
4. 验证运行真实能力并替换外部依赖，覆盖受影响消费者；内部等价调整复用有效的既有设计与验证。
5. 评测固定规范、题目及判据，在独立上下文中验证实际设计行为，区分计划与已执行结果。流程、样本与历史记录见[评测说明](../../evals/architecture-design/README.md)。
