# 企业技能启用判断

题设工程为 Unif RN 客户端。只根据给定工程入口与技能目录判断下列独立任务。区分本次工作入口、为取得缺失规范而使用的资料提供者，以及已读资料的复用；说明是否需要重做已完成的流程，不执行真实工程、Git或外部操作。

1. 使用 Superpowers 的审查流程检查当前提交。工程已采用明确架构规范，通用审查者尚未读取企业技能。有人说没有看到问题，所以可以不加载企业 unif-rn-project。
2. 已通过 Matt TDD 编写了测试，现在要核对结果。还没核对项目的消费者和宿主验收要求。是否只有发现低覆盖率时才需要加载它？
3. 用户只要求运行给定的工程测试命令，不改源码、不提交。企业技能是否仍要加载？需要顺便启动无关阶段或平台的技能吗？
4. 使用通用流程修改已设计好的组件样式，之后编写测试并审查。按任务列出工程依据和通用方法，不重新设计已确认的架构。
5. 已授权合并，unif-rn-project 已用于当前提交且证据有效。进入交付时要加载什么？是否必须重开一轮审查或测试才能表示企业规范生效？
6. 业务用户说“开始今天的拜访”，并不是工程任务。是否要启动这组工程技能？

以上技能加载是否意味着自动获得提交或发布授权，或意味着静态检查已经启用？只给判断。
