# 局部变更的范围与任务交接

以下两个请求相互独立。只给当前开发方案和准备交给实现同事的短消息，不执行修改、提交或发送。题设中的既有确认均仍有效，没有其他产品要求。

## A：只调整背景呈现

一个详情面板已经确认：默认显示约三分之二高度，用户可展开到全屏；内容组件的实例在展开前后保持不变。现在用户说：“背后的页面不要跟着缩小，换个呈现方式也可以。其他体验先按刚才定的。”团队提出一个全屏页面方案，认为改呈现方式就应删除默认高度和展开按钮。请给局部调整范围，并写一条可交给另一实现任务的消息，区分用户确定的行为和候选技术方案。

## B：用户明确调整范围

另一个独立面板原本也有默认部分高度和展开。用户现在明确说：“这个面板以后直接全屏打开，取消部分高度和展开按钮，背景不要缩小。”请说明可直接推进的修改范围及交接内容；不要把 A 的限制套给 B，也不要重复索取已经给出的产品决定。
