# 原生六库样本判据

判据不提供给作答上下文。人工阅读原始回答，不以术语命中率代替正确性；一组上下文内顺序回答六例仅是定向样本，不能给出准确率、Token 或成本收益。旧候选已经正确的判断保留，不计为新增改善。

| 请求 | 应取得的依据与行为 | 实质错误 |
|---|---|---|
| L1 | 原生应用／HAR 路由；源 SVG 与清单单一来源、生成物可追溯；显式尺寸颜色且 Icons 不依赖 Design；保留 RN 默认语义及装饰图标／父控件名称分工；原生签名尚待真实导出 | 双份资源手维、隐式主题、把 React 命名组件直接当可用 ArkUI API、只验生成成功 |
| L2 | 基础数据与平台样式拆分；应用系数只算一次，系统字号按原生规则；实际支持组件／设备／系统条件；确认只表示选择；宿主接管、重入与旧回调结算；真实布局／字体／读屏 | 整份 RN token 当纯数据、双缩放、普通模糊冒充系统材质、全卡片重设计、确认等于业务成功 |
| L3 | RN Camera 结果语义与原生实现分开；非法和已取消调用不能替换有效交互；有效新调用替换旧；clear 先确认；局部处理失败保留媒体；交付一次、选用移交、迟到文件归旧调用；相机与麦克风按意图授权 | 拍摄完成即 success、先删再确认、旧取消影响新调用、成功文件被关页删除、Mock／图片扫码外推验收 |
| L4 | 从原生 Scan 契约进入；只读借用，真实读取结束才释放一次；关闭止采用不假定原生停止；旧回调不进入新扫描；主题字号不重启设备；真实手电和结果区分 | 关闭立即释放在读文件、扫描库删外部文件、技术失败混成空结果、重复交付、根据码值发业务请求 |
| L5 | 友盟统计／分享，高德地图／POI；SDK 实际版本、依赖和签名待核；隐私前无初始化／发送或跨身份缓存；渠道回执、取消、失败与无法确认保持真实；平台 Context 和回调归宿主 | 默认改提供方、系统面板当 U-Share、唤起即成功、缺 SDK 编造签名、安装回归档技能 |
| L6 | Chat 只展示受控输入和事件，应用拥有草稿／附件／服务，键盘仅所属宿主补偿；共享候选查完整依赖／运行环境／两端产物；RN 局部只用 RN 资料；证据分层 | 业务搬入 Chat、通用 utils 大包、没有 import 就兼容、两端手维副本、扩大 RN 修复范围、Node／构建等于设备 |

各例记录：实际入口、相关资料是否可找到、保留的正确判断、实质错误、明确缺口与验证层级。资料缺失若被诚实披露不是伪造，但属于本任务需要补齐的可检索性缺口。
