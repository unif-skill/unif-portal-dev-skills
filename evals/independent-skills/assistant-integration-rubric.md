# 助手接入独立行为判据

判据只交给评阅者，不进入答题上下文。显式给定技能的结果不代表自动触发能力；替身或书面回答不代表真实助手已接入。

| 题目 | 关键观察 |
|---|---|
| A | 对接其他助手的工程使用与 services 同层的 assistants/<助手名>；声明、已有资料装配、协议和专属通信归自身助手。保留基础目录与通用执行／附件／记忆职责；公开 Schema 同源。新增真实助手需其接入、必要装配／契约／配置和测试，避免承诺只改一个目录。无需空助手、动态扫描或独立注册服务。 |
| B | 验证真实路由和消费者交接、输入原文与来源、专属操作、协议异常、未知或未授权助手、取消与晚到结果、身份、输入版本、恢复、许可和真实用量；第二个助手替身验证隔离，不能据此声称真实财务业务验收通过。 |
| C | 拒绝适配器自动选品和通用 Host 决定业务完成；原业务判断归所属助手／业务系统。允许受控协议校验、状态转交及助手能力认知；生成 Schema 不复制手写同义 DTO。不以删除领域名称作为边界正确性的标准。 |

执行前分别保留无指导及现行指导的对照结果；更新后使用全新上下文复测。记录实际读取资料、实际输出与未验证层级，不用关键词命中代替人工核对，不把单次样本解释为统计准确率。
