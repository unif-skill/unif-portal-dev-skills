## 组装与执行

1. 每题建立新的输入目录，只放该题对应技能的完整目录和 `TASK.md`。技能目录包含原有引用、元数据及资产，不改正文，不放兄弟技能、判据或其他运行结果。
2. 从表中来源截取对应二级标题之后、下一二级标题之前的正文，去掉首尾空行。将下方前缀、一个空行和该正文组成 `TASK.md`，末尾保留一个换行；不附加来源标题、其他题目或预期答案。
3. 在全新上下文发送下方执行请求，替换目录及技能名称两个参数。显式提供技能是本组条件，不能将其结果称为自动触发。

TASK.md 前缀：

```text
本次仅根据题设和提供的完整技能目录作答。各项事实是合成契约；不操作真实工程、服务、设备或业务记录。
```

执行请求：

```text
这是独立资料作答任务。只允许读取 <INPUT_DIR> 内的 TASK.md 和 <SKILL_NAME> 完整目录；不读取其他技能、记忆、父任务、其他工程、判据或历史回答，不联网、不委派、不写文件、不执行工程或真实业务。请先读 TASK.md，按题设及确有需要的本目录资料直接作答，文末列实际读取文件全路径；缺失事实如实限定，不虚构运行。出现额度或积分警告立即停止并报告，不尝试其他调用途径。
```

来源题设中的实现、服务和测试事实仅在题内成立。具体工程或 SDK 未提供时应限制结论；书面方案、实际资料读取和真实工程运行分别记录，不把题设通过写成本轮实测。
