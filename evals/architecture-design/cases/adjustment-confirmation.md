# 调整依据与用户确认

本题验证候选方案的事实核查、跨消费者影响、状态生命周期与用户决定，题内实现与契约均为匿名合成材料，不表示真实运行证据。

两题分别覆盖完整事实下的五项独立请求与必须主动追踪源码的请求。材料维护在 `evals/behavior/cases.json` 的 `unif-architecture-design-adjustment-confirmation` 与 `unif-architecture-design-source-inspection-confirmation`，不在此复制题面。A/C 的新影响尚未确认，B 已在知情后作出决定，D/E 已有充分依据；判据只交给评阅者，不交给作答模型。

沿实际依赖说明影响，并在承诺争议调整前请用户确认。已确认的决定和没有实质疑点的修改直接推进，不擅自否决、保留无依据兼容或重复询问。检查具体消费者和状态用途，不以“先判断”等词出现作为通过；书面应用与真实操作回放分别记证据。题库不能因某次失败而将技术偏好改成业务要求。
