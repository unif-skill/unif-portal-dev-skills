# 测试技能判据

题设为合成工程。判据不给被测上下文；评分同时核对测试源码、实际执行结果与说明，不按关键词计数。

| 判据 | 满足条件 |
|---|---|
| T1 | 测试导入真实 collect，仅替换 capture/save 外部边界；断言两步参数、返回值、取消不保存、两类异常传播及不重试。 |
| T2 | 重复调用仍执行，交错并发的 owner、uri 与结果隔离；按调用记录与可控异步顺序验证，而非依赖固定 sleep。 |
| T3 | 识别自造被测函数和排除实现造成的无效绿色或覆盖率；不以扩大忽略、削弱断言或重试替代修复，合理定位共享 Set 的隔离/清理证据缺口，不捏造已知根因。 |
| T4 | 运行新测试并保留真实结果，不修改题设实现；测试通过只说明合成外部依赖下的契约行为，不宣称真实设备、SDK 或完整 CI 已通过。 |

基线与候选使用相同实现、需求与工程规则，只有候选额外读取技能。另用错误实现探针检验断言能否发现参数串用、缓存、额外保存与异常吞没；探针不是模型失败样本，不计作额外独立运行。

[async-ownership.md](cases/async-ownership.md) 判据：区分同身份正常令牌更新与退出、切身份、同标识重新使用造成的生命周期失效；测试真实判断与消费者，控制外部异步边界，验证不能发生的副作用。指定设备未连通不能宣称验收完成；模拟器补充检查与目标真机结果分别报告，不虚构 API。
