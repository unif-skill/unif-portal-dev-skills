# 异步归属验证题设

这是合成模块，材料完整，只制定定向验证方案和判断目前证据，控制在 500 字内，不修改真实工程或操作设备。

契约：允许同一登录身份正常更新 token；退出或换身份后，旧操作失效，即使又登录为相同用户也不能复活。修改密码成功退出发起操作的有效身份；界面关闭不代表已发出的请求在服务端撤销。

实现一：安全操作开始时捕获 session 对象，等待网络返回后，仅当 `currentSession === initialSession` 才处理成功。已知正常刷新会创建一个新的 session 对象。

实现二：读取凭据开始时捕获 userId，等待刷新后，只要 `currentSession.userId === initialUserId` 就返回当前凭据；刷新返回值不参与判断，也不观察期间退出事件。

现有测试分别使用固定不变 session 和固定不变 userId，两个测试都成功。另有两个消息用例分别断言错误码、成功码，没有模拟等待期间的变化。

任务指定真机 `qa-phone` 验证界面和权限。当前只有 JavaScript 打包成功记录，`qa-phone` 未连通，模拟器可用，组件测试用设备替身。请给出最少但有区分度的生命周期用例、真实被测对象与替身边界，并判断哪些验证已完成、哪些仍需进行。不要虚构刷新或设备 API。
