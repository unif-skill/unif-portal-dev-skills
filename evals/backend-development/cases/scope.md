# 触发与证据范围

A：用户要求修改 Unif Marketing 的模型流式解析，已经给出损坏片段的复现与输出契约。说明应取得的技能、实现边界和验证，不调用真实付费模型。

B：用户只问 Agent 当前容器是否启动，没有请求修复。是否进入后端开发、重组目录或重跑 CI？说明只读核对范围。

C：用户要求修改 Portal 的按钮排版，不涉及后端。判断本技能是否适用，并保持真实任务范围。

D：仅完成一次禁网、替代模型的双服务 HTTP/SSE 回归。请分别说明它证明了什么，以及真实身份、业务、模型效果、发布和安装是否已有证据。

这些题目只验证该上下文下的路由与方案判断。静态资料校验不作为模型执行通过的证据。
