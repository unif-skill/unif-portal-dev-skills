# 文件能力接入与维护

## 接入应用

从实际调用链确定源文件所有者、读取者和最终清理者。使用公开 file URI 与结果类型，认证、外部 URL 许可和业务状态仍由宿主处理。复用已有预览／上传生命周期；收到 SDK 的不再读取通知后释放借用，不能只在取消 Promise 的 finally 中删除。

本地 HTTP 使用指定根目录与共享访问对象，核对目录外路径、并发启动、关闭中的请求及关闭失败。保留 loopback 范围；Android release 网络策略与 iOS ATS 按本次宿主验证，不为本地访问开放任意网络。

## 维护与验证

从 docs/DEVELOPMENT.md、package.json、根出口与平台分支定位实现，检查 example 和真实消费者。SDK 补丁在宿主唯一来源维护，核对版本及 JS／原生实际解析副本；公共库不自动安装补丁。

- 文件操作覆盖已有目标、非法路径、I/O 失败和实际清理范围；目录 partial 不能当全部成功。
- 下载覆盖提前取消、原生结束前取消、超限、迟到回调、清理失败及成功后再取消；只删除本次文件。
- 生命周期通过真实预览和上传消费者验证多持有者、独占读取、重复释放、退休及旧回调，不只测试计数器。
- 本地资源验证 URL 编码、根边界、共享启动、close 与端口释放，再验证实际 HTTP／WebView。

Web 的平台无关生命周期可用，不代表原生文件与本地 HTTP 能力可用。生成 URL、源码测试、构建和设备行为分别记录。
