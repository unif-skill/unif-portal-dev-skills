# @unif/harmony-umeng 实施规范

本文定义 API 26 原生友盟库的职责与验收，不声明 RN 导出在鸿蒙已经可用。共同语义见 RN Umeng（规范源相对路径：`libraries/react-native-umeng.md`），真实方法、厂商依赖和回调要求由采用版本的鸿蒙 SDK 与公开源码确认。


## 1. 职责与依赖

友盟提供初始化、就绪与渠道查询、统计、分享和分享面板组合；分享与统计不能被系统分享示例替换。业务同意记录、身份、截图、上传、地图／POI、导航和业务结果在应用。地图／POI 使用高德，不因 SDK 示例改为华为 Map Kit，也不放进 Umeng。

[友盟鸿蒙 U-Share 概述](https://devs.umeng.com/docs/128606/detail/2938160)要求配合 `@umeng/common`、`@umeng/analytics`、`@umeng/share`；实施时锁定实际版本，核对 Stage、字节码、权限、渠道依赖和宿主回调。文档概述或目录列出某渠道，不足以证明该版本已支持 RN 所采用的全部目标。包名、方法和宿主注册按真实文档验证，不搬用 iOS Universal Link／Android 回调配置。

面板消费 [Design](https://github.com/unif-design/unif-platform-architecture/blob/main/libraries/harmony-design.md#1-职责与依赖) 及必要图标；品牌渠道标识保留品牌语义。只有面板需要 UI 宿主，独立统计／查询操作不要求先创建业务页面或全局面板容器。


## 2. 公开契约与对齐

| 能力 | 必须保持的语义 |
|---|---|
| 初始化／就绪 | 应用取得真实隐私同意后交付完整配置；查询读取真实就绪，错误不冒充 false；未初始化操作不能自行补初始化 |
| 渠道查询 | 只报告本应用已配置目标与真实安装状态；未配置不冒充未安装；不因缺渠道自动开商店或换提供方 |
| 内容分享 | 目标、文字／图片／链接及缩略图按明确输入处理；沿当前 HTTP(S)、非空和参数校验，保留原内容快照；不顺带截图或上传 |
| 统计／用户关联 | 参数校验及调用交接不等于事件已上报或业务登录；不读取账号 store，不新增离线队列、隐式重试或跨身份事件缓存 |
| 面板 | 实例拥有本次选择；modal／floating 的遮罩、触摸、布局／关闭事件和默认值保持原义，两种展示复用同一分享操作 |

成功必须有本次渠道对应的 SDK 成功回执，只证明该回执；取消需来自尚未发起分享的用户选择或厂商明确取消。未知、丢失或无法验证的回执按真实失败／无法确认原因交接，不能宣布外部分享一定没发生，更不能将拉起 App、关闭面板或 void 返回当作成功。不自行发明新的公开结果枚举，原生结果映射须能对齐 RN 的业务含义。


## 3. 状态、资源与结束

进程 SDK 就绪、分享调用和面板呈现各自拥有状态。初始化配置是不可变快照，同配置并发共享在途结果，开始后不能换配置；失败等待明确重试。库不维护第二份用户同意事实；同意前不初始化、发送统计或私自缓存业务事件。撤回同意、账号退出／切换由应用按真实授权通知并核对厂商可停止范围，不能声称 SDK 不支持的反初始化已经完成。

每个面板实例至多一个未结束选择，重入保留 busy、无宿主保留不可用语义；原生分享通道另按 SDK 实际并发能力保护。UIContext、Ability 回调和订阅绑定真实宿主，不存入全局工具，不由页面分别维护一套原生分享链。

分享开始前的关闭／取消／宿主结束可结束选择。发给厂商后，取消呈现不伪造取消外部分享；原调用继续接收真实回执并收尾，旧回调不能操作新面板。SDK 确需的临时资源由创建者管理到真实读取完成，不能关页即删。配置、密钥、分享内容和账号标识不进入日志。

面板渠道、安装状态和取消动作具有名称与焦点顺序；floating 的触摸穿透与 modal 的内部阻止误关闭分别保留。字号／主题／材质更新不能重新初始化、重新发现渠道或重复分享，装饰不成为读屏操作。


## 4. 验证与采用

源码／自动化覆盖同意边界、初始化合并和配置锁定、未就绪、内容校验、各回执、未知响应、busy、旧回调、面板关闭与厂商操作的区别；直接分享和面板均使用同一能力。统计检查有限数值、用户关联及退出交接，不以 void 返回证明服务收妥。

HAR 和独立宿主构建核对依赖、配置及回调接线；真机按真实渠道、App 安装／未安装、前后台和返回路径分别验证文字／图片／链接、成功／取消／失败及读屏。账号同意、实际统计接收、Portal／H5 和图片预览浮动面板另做业务验收。

缺 SDK、凭据或目标 App 时可以完成契约、依赖核查和状态交接测试；这些缺口仍不能填为真实分享／统计通过，系统面板演示不能补足证据。
