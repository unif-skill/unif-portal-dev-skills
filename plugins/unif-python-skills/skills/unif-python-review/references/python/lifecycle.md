## 4. 运行与资源生命周期

每项异步操作有明确所有者，负责启动、取消、等待完成、取得异常和释放资源。关闭、取消、超时及迟到结果按照既有运行契约处理；单轮状态、宿主任务集合及锁不因拆文件分散到多个协调者。

外部客户端由应用或所属操作组装并关闭。返回业务结果前后的连接收尾、持久化等待和公开过程计时按既有契约保留；网络断开不直接表示业务完成。

跨表原子操作保持同一连接与事务。事务内辅助函数接收实际连接和必要值，不自行提交、回滚或释放调用方的连接。结构重构应核对 SQL、事务开始/提交位置、版本条件与失效顺序。

输入大小、传输范围和网络故障等待按所属契约由运行代码落实；正常轮次不设置固定总时长、调用次数或营销输出 token 上限。重试以实际错误、幂等性及授权为依据，不隐藏额外模型或业务调用。凭据、原始附件和用户全文不进入诊断日志。
