# 地图能力接入与维护

## 应用消费

先定位应用已有地图、定位和地点查询入口及实际包版本。宿主提供稳定的权限访问、相同 Context 的键盘能力与 URL 操作；选点 Host 放入当前主题、手势和安全区环境。不能用空权限或键盘替身声称原生接线完成。

按当前配置与真实事件组合初始定位、搜索、候选恢复和确认。业务校验沿用 beforeConfirm 等公开能力，取消确认保留当前交互。场景负责采用确认结果；库不替业务保存、生成地点资料或增加后台定位。

## 原生前置与维护

从库内 docs/DEVELOPMENT.md、package.json、src/index.ts、src/index.web.ts 和对应模块追踪实现。SDK 的必要补丁由宿主维护；核对精确版本、来源及 JS／原生实际解析副本，安装本库不代表补丁已应用。不在库或技能另存补丁副本。

公开配置、事件、取消或结果改变时检查 example 和真实消费者；不把 RN 用法移植为未实现的鸿蒙接口。

## 定向验证

- 选点核对真实控制器与消费者：搜索／候选交错、确认拒绝、取消与重新打开、旧回调和地图实例保持。
- 定位核对单次取消与持续观察接替、旧停止句柄、权限结果和实际坐标；地点查询保持合法零值、缺失字段及坐标系边界。
- 外部唤起验证系统可处理／不可处理及取消时序，不能把系统交接当到达目的地。
- SDK 集成使用宿主实际修补副本。真实键盘、手势、定位和厂商服务需要设备证据；缺少 key 或设备时明确限制，不扩展权限或改用其他供应商。
